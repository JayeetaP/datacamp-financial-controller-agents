# Reconciliation triage

Use deterministic control results for amounts, aging, recurrence, and close proximity. Separate a
timing item from a true break only when current evidence supports the classification. If a control
has failed repeatedly and meets the preventive policy, escalate before close even when root cause
is unknown. Name the owner and requested evidence; do not manufacture a resolution.
