# Close package writing

- Use validated calculation and finding objects only.
- Place evidence IDs beside material conclusions.
- State unresolved questions and the named reviewer action.
- Keep system recommendation separate from human decision.
- Do not use `approved`, `posted`, or `cleared` unless a human action record proves it.
- Label all outputs `SYNTHETIC DATA — EDUCATIONAL DEMO`.
