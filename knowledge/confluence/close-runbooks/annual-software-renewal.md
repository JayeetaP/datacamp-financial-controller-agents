# Investigating a software-renewal variance (synthetic)

When software expense is materially above budget and the journal description indicates a renewal:

1. Retrieve the current invoice and linked contract.
2. Confirm the service start and end dates from the current contract.
3. Resolve the canonical prepaid policy ID.
4. Calculate the current-period expense and remaining prepaid with the approved tool.
5. Prepare an unposted draft only after current evidence and the calculation agree.

Prior-period cases are directional context only.
