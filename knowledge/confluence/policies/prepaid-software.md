# Published prepaid-software policy (synthetic)

Annual software renewals above the capitalization threshold should be checked against canonical
policy `POLICY-PREPAID-003`. Verify the current invoice amount and the contract service period. Use
the deterministic prepaid-schedule tool for the allocation. The canonical rule in `controls/`, not
this published page, controls the calculation.
